12 种灯语

颜色由风险语义锁定，只允许调整动画节奏。

多会话 风险 聚合

多个 Codex 会话同时运行时按优先级自动聚合。阻塞和授权永远优先显示，不会被新的工作事件覆盖。同级取最近状态。

Codex Hook 集成

安装包自动写入用户级 Codex hooks。UserPromptSubmit → 绿灯脉冲，PermissionRequest → 红灯慢呼吸，Stop → 绿灯双闪后归位。

macOS 原生 渲染

纯 AppKit 绘制：菜单栏横向三灯图标、桌面磨砂玻璃悬浮窗、Touch Bar 视图。不依赖网页窗口，signal-light CLI 编译为原生二进制。

分级 租约 与历史

分级租约自动过期（工作 30min / 关注 2h / 关键 24h / 完成 6s）。超时无心跳的状态标记为失联。本地保留 24h/200 条最小状态历史，不记录提示词。

多会话聚合规则
已阻塞> 等待授权> 等待关注= 状态失联> 工作中> 已完成> 空闲

安装

支持 macOS 11 及以上版本。下载经过签名和公证的安装包，安装后在 Codex 的 /hooks 面板确认首次发现的 Hook。

$ open "/Applications/Signal Light.app"
$ signal-light list # 列出所有灯语
$ signal-light play working # 预览工作状态
$ signal-light doctor # 诊断接线状态
