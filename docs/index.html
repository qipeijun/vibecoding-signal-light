状态灯常驻菜单栏和桌面悬浮窗。你可以继续写代码、看文档或离开屏幕，等 Agent 需要权限或结果需要确认时再回来处理。

菜单栏与悬浮窗

小尺寸、低打扰，支持置顶显示。工作中保持绿色脉冲，需要关注时切换黄灯或红灯。
